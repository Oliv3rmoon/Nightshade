**Video profiles, Safe Launch and Quick settings, and homebrew in the Library.** Choose Minimum, Recommended, High or Ultra for every game or for one, start a game once in safe mode when it won't start, and change a game's video from a quick panel. Homebrew NROs are listed beside your games with their own names and icons, and newer games' ZBIC-compressed code must decode whole. Not confirmed on a console yet.

### New

- **Video profiles.** **Settings > Video > Video profile** sets the resolution, upscaling filter, ASTC textures, **Faster GPU emulation** and **Asynchronous shaders** at once: **Minimum** (0.75x with AMD FSR, the faster GPU accuracy, asynchronous shaders), **Recommended** (1x, Bilinear: what a new install has), **High** (1.5x, Bicubic) and **Ultra** (2x, Bicubic). Each turns frame generation and post-processing off, and keeps ASTC textures compressed. A game's own Video has the same row, first: a profile chosen there is that game's own. Change one of those settings by hand and the profile shows **Custom**. Tears of the Kingdom has profiles of its own that keep the console's 4 GiB and compressed textures in every one, what v1.010.005 found it needs. See [Video profiles](https://github.com/Oliv3rmoon/Nightshade/blob/v1.010.007/docs/SETTINGS.md#video-profiles).
- **Quick settings.** Options on a game, in the Library, on the home screen or on its settings page, opens a panel with **Play**, **Start in safe mode**, its video profile, resolution, upscaling filter, renderer, FPS overlay and frame generation. A change is saved for that game at once; Triangle opens all of its settings.
- **Safe Launch.** **Start in safe mode** starts a game once at 1x, Bilinear, compressed ASTC, a 1080p output at 60 Hz, with no frame generation or post-processing, every Performance switch at its default, 4 GiB, and its mods and cheats off. It keeps the renderer, the console mode, your controls and the language. Nothing is saved: the next start uses your settings as they are. When a game could not start, the home screen's message says **Start it in safe mode** (Options). The launch report says `Safe mode (this start only)`. See [Safe Launch](https://github.com/Oliv3rmoon/Nightshade/blob/v1.010.007/docs/SETTINGS.md#safe-launch).
- **Recently played on the Nightshade and Slate home screens.** A column of the recent games' covers stands between the game's details and the grid: Right from the details reaches it, the details show the game focused there, and Cross plays it.
- **The game's case.** A game you start comes forward as a case that turns to face you, its cover on the front and its edge on the spine. With **Reduce motion**, or for a game without a cover, the cover comes forward as before.
- **More in the overlay.** The FPS overlay can say the last second's average frame time before its worst (`33.3/41.2MS`), how much of the memory Nightshade holds for itself (its heap) is in use (`HEAP 1.1/1.5G`) with `LOW` while the memory pool is short, and how far the game's saved shaders are built while it plays (`SHD 45%`). **Settings > Video > Overlay options** has a switch for each. They are on for a new install; settings saved by an earlier version keep the line as it was until you turn them on. See [The performance overlay](https://github.com/Oliv3rmoon/Nightshade/blob/v1.010.007/docs/SETTINGS.md#the-performance-overlay).
- **A game's own console memory.** A game's own Performance settings have **Memory** after the speed limit, as **Settings > Performance** has for every game.
- **Homebrew (NRO) in the Library.** `.nro` files in `roms/`, or together in a folder of it such as `roms/homebrew/`, are listed with the name and icon in their assets (else by their file name) and start like a game. See [Homebrew and advanced files](https://github.com/Oliv3rmoon/Nightshade/blob/v1.010.007/docs/INSTALL.md#homebrew-and-advanced-files).
- **Advanced files: NSO, NCA, NAX, KIP and unpacked ExeFS.** The Library also lists programs on their own, marked **(advanced)** after their format: a lone NSO; a Program NCA, with its game's name, icon and control data from the Control NCA beside it when an NSP was unpacked into a folder; a NAX copied off an SD card under its content ID; a KIP; and a folder holding `main` and `main.npdm`, listed as `EXEFS`. Each starts only with what it needs beside it, and most games do not start from one. Only the NCAs and NAXs the keys read as programs are listed, so an unpacked NSP's other NCAs are not.
- **The community in About.** About now names the community's Discord server, **nightly**, with its address (`discord.gg/pSqgRU3YP9`) and a QR code your phone opens it with. The first time Nightshade opens with this version, a card shows the same once over the home screen; any button closes it, and it doesn't come back.

### Fixes

- **A lone NSO starts.** It was loaded into a process that had not been laid out yet, and the file system answered none of its calls. Its process is now laid out first and known to the file system, as an NRO's is.
- **An unpacked ExeFS starts with all its modules.** Its `main` was taken for a lone NSO and started without its `main.npdm`, `rtld`, `sdk` or `subsdk`. A `main` with `main.npdm` beside it now starts its folder, as yuzu did, and the file system answers its calls.
- **A KIP can use the file system.** Its first file system call failed; it is now answered, as an NRO's is.
- **A NAX is read wherever it is.** One was read only at its place on an SD card (`registered/000000XX/<content ID>.nca`); one that keeps its content ID as its name is now read in `roms/` too, with the same keys.
- **Code compressed with ZBIC must decode whole.** Games made for Switch system software 22.0.0 and later compress their code with ZBIC, a variant of zstd, instead of LZ4; Nightshade has read it since v1.000.110, with Atmosphère's decoder. A part of the code that decoded to fewer bytes than the game gives for it was taken anyway, the rest left as whatever was there; such a game now stops at its load with an error instead, as an LZ4 one does. The host checks now decode ZBIC data and NSOs made in that format, and start a ZBIC NSO in the emulator.

### Install

From 1.005.102 or later, **Update now** applies it. If it doesn't, send `/data/prosperoeden/logs/updater.log`. From an older version, copy this ZIP's `PPSA99008` folder over yours.
